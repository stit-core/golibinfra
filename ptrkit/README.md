# ptrkit

Два generic-хелпера для работы с указателями: `Ptr` (значение → `*T`, либо `nil`
если значение нулевое) и `Deref` (`*T` → значение, либо нулевое если `nil`). Без
зависимостей, без I/O — чистые функции для заполнения и чтения опциональных полей
(`*string`, `*int64`, …), где «пустое/0» означает «не задано».

## Импорт

```go
import "git.stit.tech/stit-core/golibinfra/ptrkit"
```

Версия и `go get` — см. [корневой README § Использование в проекте](../README.md).

## Быстрый старт

```go
type Row struct {
	Note    *string
	Count   *int64
}

row := Row{
	Note:  ptrkit.Ptr(s),       // nil, если s == ""
	Count: ptrkit.Ptr(n),       // nil, если n == 0
}

note := ptrkit.Deref(row.Note) // "" , если row.Note == nil
```

Точные сигнатуры:

```go
func Ptr[T comparable](v T) *T
func Deref[T any](p *T) T
```

## Observability

Кит **ничего не эмитит**: ни метрик, ни спанов, ни логов — это чистые функции над
значением и указателем.

## Инварианты и подводные камни

- **`Ptr` сводит нулевое значение к `nil`.** Пустая строка, `0`, `false` дают
  `nil`, а не указатель на нулевое значение. Если нужно отличать «задано нулём» от
  «не задано» — `Ptr` не подходит, бери `&v` напрямую.
- **`Ptr` требует `comparable`.** Тип должен поддерживать `==` (строки, числа,
  bool, указатели, структуры из comparable-полей). Для `time.Time` сравнение по
  `==` ненадёжно (монотонные часы / location) — для времени используй helper с
  `IsZero()`-семантикой, не `Ptr`.
- **`Deref` безопасен на `nil`.** Возвращает нулевое значение `T`, разыменования
  `nil` не происходит.
