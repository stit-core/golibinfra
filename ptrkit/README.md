# ptrkit

Generic-хелперы для указателей: `Of` (значение → `*T` всегда), `OmitZero`
(значение → `*T`, либо `nil` если значение нулевое) и `Deref` (`*T` → значение,
либо нулевое если `nil`). Без зависимостей, без I/O — чистые функции для
заполнения и чтения опциональных полей (`*string`, `*int64`, …).

## Импорт

```go
import "git.stit.tech/stit-core/golibinfra/ptrkit"
```

Версия и `go get` — см. [корневой README § Использование в проекте](../README.md).

## Быстрый старт

```go
type Row struct {
	Note  *string
	Count *int64
}

row := Row{
	Note:  ptrkit.OmitZero(s), // nil, если s == "" → NULL в колонке
	Count: ptrkit.Of(n),       // указатель всегда, в т.ч. на 0
}

note := ptrkit.Deref(row.Note) // "", если row.Note == nil
```

Точные сигнатуры:

```go
func Of[T any](v T) *T             // всегда указатель
func OmitZero[T comparable](v T) *T // nil на нулевом значении
func Deref[T any](p *T) T
```

## Observability

Кит **ничего не эмитит**: ни метрик, ни спанов, ни логов — это чистые функции над
значением и указателем.

## API

| Символ | Роль | Когда использовать |
|---|---|---|
| `Of(v)` | Адрес копии `v` | Нужен указатель на любое значение, включая нулевое: `*bool` со значением `false`, `*int` со значением `0` |
| `OmitZero(v)` | Адрес копии `v` либо `nil` на нулевом значении | Опциональное поле, где «пусто» означает «не задано»: `NULL` в колонке, отсутствие поля в JSON |
| `Deref(p)` | Значение либо нулевое на `nil` | Чтение опционального поля без проверки на `nil` |

Оба конструктора берут **копию** аргумента: последующее изменение переменной не
видно через полученный указатель.

## Инварианты и подводные камни

- **Имя говорит о семантике.** `Of` — «указатель на это значение», `OmitZero` —
  «опустить, если пусто». Короткого имени со скрытым правилом нет намеренно:
  выбор между ними — это выбор того, как читается `nil` у поля.
- **`OmitZero` требует `comparable`.** Тип должен поддерживать `==` (строки,
  числа, bool, указатели, структуры из comparable-полей). Для `time.Time`
  сравнение по `==` ненадёжно (монотонные часы / location): `time.Time{}.In(loc)`
  даёт `IsZero() == true`, но `!= time.Time{}` — и `OmitZero` вернёт указатель.
  Для времени используй helper с `IsZero()`-семантикой.
- **`OmitZero[any]` не паникует на несравнимом значении.** Сравнение идёт с
  nil-интерфейсом: динамические типы разные, до сравнения значений дело не
  доходит. Слайс/map в `any` вернут указатель.
- **`Deref` безопасен на `nil`.** Возвращает нулевое значение `T`, разыменования
  `nil` не происходит.
